# EnemyBuster
本プラグインは、**オンラインスクール「デイトラ Javaコース 中級編」**のカリキュラムに沿って開発しました。
講師の実装内容を模倣しつつ、実際に自分の手を動かして理解を深めながら構築しています。
（完全に1から自作したものではありませんが、構成・動作・設計意図の理解を意識して学習しています）

### 基礎
- オブジェクト指向によるクラス分け  
- APIでのリファクタリング  
- MyBatis実装（予定）  
- JDBCによるDB接続とスコア保存  
- Bukkit APIを用いたイベント処理（敵スポーン・スコア加算など）

### 実装要素
- **ミニゲームの基本ループを自作**  
  BukkitRunnable で 5 秒刻みのスポーン → 時間減算 → 終了処理までを構築。  

- **難易度パラメータでゲーム分岐**  
  `getEnemy(difficulty)` で敵プールを切替。  

- **スコア保存と履歴参照**  
  DB へ `INSERT`、`/list_a` で直近スコア表示。  

- **安全系の配慮を実装**  
  - コマンドの実行者チェック（Player以外を弾く）  
  - 「自分が湧かせた敵か」を `spawnEntityList` で判定  

- **プレイヤー状態の初期化**  
  装備付与やポーション効果解除。
